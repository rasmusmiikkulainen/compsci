The truth table corresponds to the truth table of the boolean statement XNOR (exclusive nor).
```python
# XNOR in python:
not ((a or b) and not (a and b))
```
Truth table of XNOR:
| A | B | A XNOR B |
| --- | --- | --- |
| False | False | True |
| False | True | False |
| True | False | False |
| True | True | True |
